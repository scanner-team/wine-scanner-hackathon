# Данные каталога

Эталонные данные, с которыми сравнивается фото пользователя. 2103
позиции, сверено с исходной выгрузкой (0 расхождений, 0 дублей).

## Структура

```
data/catalog/
  wines.csv                — таблица всех 2103 позиций
  photos/                  — эталонные фото, 2103 файла (по одному на позицию)
  photos_thumb/            — превью для сетки каталога на сайте, 2103 файла
  vlm_raw/                 — <slug>.json, прочитанный VLM текст этикетки (кэш)
  vectors/
    references.npz         — эмбеддинги (Qwen3-VL-Embedding-2B, 2048-мерные), ключ — slug
    references_full.csv    — манифест slug → путь к фото → название
    embed_summary.json     — сводка расчёта векторов
```

Итого ~259 МБ, ~6300 файлов. Данные коммитятся прямо в репозиторий: самый
крупный файл — 18 МБ (`references.npz`), Git LFS не требуется.

## Поля `wines.csv`

Заголовки колонок — на русском. Кодировка — UTF-8 с BOM (`utf-8-sig`).

| Колонка | Что это |
|---|---|
| `Slug` | Уникальный идентификатор позиции — то, что возвращает сервис |
| `Название вина` | Название |
| `Винодельня` | Производитель |
| `Регион` | Регион производства |
| `Сорт винограда` | Сорт |
| `Категория` | Категория (например, «Красное») |
| `Цвет` | Цвет вина (текстом) |
| `Описание` | Текстовое описание |
| `Фото` | Имя файла эталонного фото |

## Целостность

`references.npz` (2103 ключа), `references_full.csv` (2103 строки) и
`wines.csv` (2103 строки) согласованы по slug; каждому slug соответствуют
файл в `photos/` и в `vlm_raw/`.

## Особенность каталожных фото

Часть эталонных фото — низкого разрешения (унаследовано из исходных
данных). Сервис помечает такие случаи как `low_res_warning` (см.
`../docs/API.md`, `../docs/METRICS.md`).
