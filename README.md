# Wine Scanner

Сервис распознавания вина по фотографии бутылки. Принимает фото, находит
соответствующую позицию в каталоге (2103 вина) и возвращает конкретное
вино вместе с пятёркой ближайших кандидатов.

## Как работает

Пайплайн объединяет два независимых сигнала:

1. **Визуальный поиск.** `Qwen3-VL-Embedding-2B` превращает фото в вектор
   и находит 5 ближайших позиций каталога по косинусному сходству.
2. **Чтение этикетки.** `Qwen3-VL-4B-Instruct` (VLM) читает текст с
   этикетки — название, производитель, сорт, категория — в
   структурированный JSON.
3. **Реранкинг.** Детерминированные правила сверяют прочитанный текст с
   карточками пяти кандидатов и уточняют порядок. Это позволяет различать
   вина одной винодельни с почти одинаковыми этикетками.

Ответ: `slug` вина, уверенность, пятёрка кандидатов с оценками похожести.
Обе модели — предобученные (Qwen3-VL, Alibaba), без дообучения под
каталог. Полное описание — [`ARCHITECTURE.md`](ARCHITECTURE.md).

## Быстрый старт через Docker

```bash
cp .env.example .env
docker compose up
```

Поднимает два контейнера: `vllm` (чтение этикетки) и `winescanner`
(визуальный поиск + API + веб-страница). Модели скачиваются с Hugging
Face при первом запуске (~13 ГБ). Готовность — `curl
http://localhost:8080/health`.

Установка и запуск без Docker, переменные окружения, systemd —
[`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).

## Требования

- Linux, NVIDIA GPU с CUDA (проверено на RTX 4090; достаточно ~16–24 ГБ
  VRAM, на меньших картах снизить `--gpu-memory-utilization`).
- Docker + `nvidia-container-toolkit` (для Docker-пути) либо Python 3.12
  (для ручного запуска).
- Интернет для загрузки моделей при первом старте.

## После запуска

- `http://localhost:8080/` — веб-страница поиска.
- `http://localhost:8080/docs` — Swagger UI, ручной вызов эндпоинтов.
- `http://localhost:8080/health` — статус сервиса.

## Характеристики

- Время ответа: 1.5–6 с на фото (RTX 4090).
- Один запрос за раз: обе модели делят один GPU, запросы сериализуются.
- Часть эталонных фото каталога — низкого разрешения (унаследовано из
  исходных данных); такие случаи помечаются в ответе (`low_res_warning`).
