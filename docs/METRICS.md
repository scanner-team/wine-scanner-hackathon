# Как сервис выбирает победителя и считает точность

Что значат числа `similarity` и `rerank_score` под карточками топ-5, как
выбирается финальный ответ и как считается точность.

## Три шага от фото до ответа

1. **Похожесть по картинке.** Фото сравнивается с фото всех вин каталога
   (2103 позиции), для каждого — число похожести от 0 до 1. Берутся 5
   самых похожих — «топ-5».
2. **Чтение текста с этикетки.** То же фото читает вторая модель:
   название, производитель, сорт, категорию.
3. **Уточнение по тексту.** Прочитанный текст сверяется с карточкой
   каждого из 5 кандидатов. Совпадение даёт кандидату надбавку к
   похожести. Побеждает наибольшая сумма (похожесть + надбавка).

Смысл шага 3: два вина одной винодельни бывают почти одинаковы на фото,
но различаются по тексту этикетки.

## Модели

| Модель | Что делает | Шаг |
|---|---|---|
| `Qwen3-VL-Embedding-2B` | Превращает фото в эмбеддинг, по которому считается похожесть | 1 |
| `Qwen3-VL-4B-Instruct` | Читает этикетку и отвечает текстом (JSON) | 2 |

Обе — семейство Qwen3-VL, работают локально, без облачного API.

## Термины

- **Эмбеддинг** — числовой «отпечаток» фото. У похожих фото отпечатки
  близки; сравнивать отпечатки надёжнее, чем пиксели (ракурс, свет, фон
  всегда разные).
- **Косинусное сходство (`similarity`)** — число 0–1, близость двух
  отпечатков.
- **VLM** — модель, которая видит фото и отвечает текстом про его
  содержимое (в отличие от эмбеддинга, не сравнивает фото между собой).
- **Реранкинг (`rerank_score`)** — пересортировка топ-5 с учётом текста
  этикетки (шаг 3).
- **IDF** — вес слова по редкости: редкое слово (название вина) весит
  больше частого («сухое»); совпадение по редкому слову — более сильный
  сигнал.
- **Confidence** — `similarity` финального победителя; влияет только на
  пометку «найдено уверенно / нет», не на выбор победителя.
- **Low-res референс** — эталонное фото вина в каталоге низкого качества
  (унаследовано из исходных данных). Если победитель — такое вино,
  показывается предупреждение.

## Формула

```
rerank_score = similarity + 0.15 × текстовое_совпадение
```

`текстовое_совпадение` — число 0–1 из пяти частей (сумма до 10 баллов,
делится на 10):

| Что сравнивается | Баллов |
|---|---|
| Производитель (винодельня) | 3 |
| Сорт винограда | 2 |
| Цвет/категория | 1 |
| Название вина (текстовая похожесть) | 1 |
| Совпадение слов этикетки (с учётом IDF) | 3 |

Если фото победителя по шагу 1 — low-res референс, шаг 3 пропускается:
победителя выбирают по чистой похожести картинок (доверять сверке текста
с плохим фото ещё рискованнее).

`rerank_score` может быть больше 1 — надбавка прибавляется поверх
`similarity` и не нормируется. Число служит только для сравнения 5
кандидатов между собой, не читается как вероятность.

## Порог confidence

В обычном режиме сервис всегда отдаёт ответ; порог влияет только на поле
`found` («найдено уверенно» / «низкая уверенность»). Подобран так, чтобы
не терять верные совпадения на проверочной выборке, отсекая большинство
случаев, когда на фото вина нет в каталоге.

## Точность (F1)

- **TP** — сервис ответил правильно.
- **FP** — ответил, но неверно.
- **FN** — правильный ответ существовал, но не выбран.
- **Precision** — доля верных среди ответов сервиса.
- **Recall** — доля найденных среди правильных ответов.
- **F1** — среднее гармоническое precision и recall.

На каждое фото — ровно один правильный ответ, и сервис всегда выдаёт
ровно один. При такой постановке `Precision = Recall = F1 = (верных
топ-1) / (всего размечено)`, то есть F1 численно совпадает с обычной
accuracy.

**Top-5 recall** — доля случаев, когда правильный ответ был где-либо в
топ-5. Разница между точностью топ-1 и Top-5 recall показывает, сколько
ошибок — это «верный ответ был рядом, но не выбран», а не «модель не
поняла, что за вино».

## Разметка

Сервис не знает истину, пока человек не подтвердит через `POST /v1/mark`.
Исходы:

| Отметка | Значение |
|---|---|
| Совпадает с ответом сервиса | Верно |
| Другая карточка из пяти | **Ошибка сканера**: верный был в топ-5, но не выбран |
| «Нет в топ-5», confidence ниже порога | Сервис честно предупредил о неуверенности и не угадал |
| «Нет в топ-5», confidence выше порога | **Уверенный промах**: уверен, но полностью неверно (обычно вино не из каталога, визуально похожее) |
| «Нет в каталоге» | Не ошибка распознавания, исключается из знаменателя точности |

## Радиальная вкусовая диаграмма

Под результатом — «колесо вкуса»: 8 осей, шкала 0–5.

**Структурные оси (4):**

| Ось | Источник | Что это |
|---|---|---|
| Сладость | категория (сухое/п.сухое/сладкое/брют) в названии/описании | официальная категория вина |
| Кислотность | справочник по сорту | типичная характеристика сорта (энология) |
| Танинность | справочник по сорту | то же |
| Тело | справочник по сорту | то же |

Для смешанных сортов — среднее по компонентам. Для сортов вне справочника
ось `null` (не подставляется примерное число), рисуется полой точкой с
подписью «нет данных».

**Ароматические оси (4)** — топ-4 семьи по распространённости в
описаниях: фрукты/ягоды, цветы, цитрус/тропики, пряности. Оценка по числу
разных слов семьи в описании: 0 → 0, 1 → 3, 2+ → 5.

Границы применимости: это не дегустация и не лабораторный анализ.
Сладость и ароматы взяты из текста производителя, структура — общий
профиль сорта, не конкретной бутылки; на диаграмме это подписано.
