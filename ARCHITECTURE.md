# Архитектура

## Пайплайн

```
                         ┌─────────────────────────────────────┐
                         │  Фото бутылки (пользователь)          │
                         └───────────────────┬───────────────────┘
                                             │
                              уменьшение до ~2 млн пикселей
                                             │
                     ┌───────────────────────┼───────────────────────┐
                     │                                               │
                     ▼                                               ▼
      ┌───────────────────────────────┐            ┌───────────────────────────────┐
      │ Qwen3-VL-Embedding-2B          │            │ Qwen3-VL-4B-Instruct           │
      │ визуальный поиск (embedding)   │            │ чтение этикетки → JSON         │
      └───────────────┬───────────────┘            └───────────────┬───────────────┘
                       │                                            │
        сравнение с 2103 векторами                                  │
              каталога (cosine)                                     │
                       │                                            │
                       ▼                                            │
            ┌─────────────────────┐                                 │
            │ Топ-5 кандидатов     │◄───────────────────────────────┘
            │ (по похожести фото)  │      сверка текста запроса
            └──────────┬───────────┘      с карточками топ-5
                       │
                       ▼
      ┌─────────────────────────────────────┐
      │ Правила сравнения полей (без нейросети) │
      │ — реранкинг: similarity + бонус за     │
      │   совпавший текст                       │
      └───────────────────┬─────────────────────┘
                          │
                          ▼
              ┌───────────────────────┐
              │ Финальный ответ:        │
              │ slug + уверенность +    │
              │ топ-5 с оценками        │
              └───────────────────────┘
```

Два независимых сигнала — визуальное сходство (embedding) и текст с
этикетки (VLM) — объединяются на финальном шаге. Это решает основную
сложность задачи: одна винодельня часто выпускает несколько вин с почти
одинаковой бутылкой («трудные пары», near-duplicate), которые по одной
картинке неразличимы, но различаются по тексту этикетки.

## Роли моделей и кода

| Компонент | Что делает | Чем является |
|---|---|---|
| `Qwen3-VL-Embedding-2B` | Превращает фото в вектор, ищет 5 ближайших векторов каталога по косинусному сходству | Нейросеть |
| `Qwen3-VL-4B-Instruct` | Читает этикетку и возвращает структурированный JSON: название, производитель, сорт, категория, сырой текст | Нейросеть (VLM) |
| Реранкинг | Сверяет поля JSON с карточками топ-5, начисляет бонус за совпадения (производитель +3, сорт +2, категория +1, название +1, совпадение слов с учётом редкости +3) | Детерминированный код |
| Гейт по разрешению эталона | Если у топ-1 кандидата эталонное фото каталога низкого разрешения, шаг реранкинга пропускается — ответ по чистой похожести картинки | Детерминированный код |
| Порог уверенности | Финальный `similarity` победителя сравнивается с порогом; ниже порога ответ помечается как неуверенный | Детерминированный код |

Обе нейросети — из семейства Qwen3-VL (Alibaba), разного назначения:
`Embedding` даёт числовую близость «похоже / не похоже», `Instruct`
отвечает текстом про содержимое конкретного фото. Обе используются
предобученными, без дообучения под каталог.

## Почему гибрид, а не одна модель

Чистый визуальный поиск (без чтения этикетки) на полном каталоге даёт
точность около 84% с систематической ошибкой: вина одной винодельни с
похожей этикеткой путаются между собой. Добавление независимого чтения
текста и сверки полей — ключевая техническая идея, поднимающая точность
на «трудных парах».

## Где считается пайплайн

Весь расчёт — локально, на одной машине с NVIDIA GPU (CUDA),
self-hosted моделями. Обращений к платным облачным API в рабочем
пайплайне нет.

### Один GPU, без распараллеливания

Визуальный поиск и чтение этикетки выполняются **последовательно**.
Параллельный запуск двух тяжёлых вычислений на одном GPU медленнее
последовательного — GPU не делится между ними эффективно. На машине с
несколькими GPU (по одному под каждую модель) ограничение снимается.

### Время ответа

Полный ответ (эмбеддинг + чтение текста, последовательно) — 1.5–6 секунд
на RTX 4090 (диапазон по контрольному набору из 20 фото). Основной вклад
в скорость даёт бэкенд читающей модели — vLLM (обоснование выбора —
[`EXPERIMENTS.md`](EXPERIMENTS.md)).

## Не входит в текущую схему

- **Нейросетевой реранкер** — реранкинг реализован только
  детерминированными правилами (таблица выше).
- **Отдельный OCR-движок** — текст читает та же VLM, что видит картинку.
- **Дообучение моделей под каталог** — обе модели используются
  предобученными.
