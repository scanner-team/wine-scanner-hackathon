# static/ — фронтенд

`index.html` — страница поиска: один файл, без сборки и фреймворков
(HTML + `<style>` + vanilla JavaScript). Читается сервисом с диска на
каждый запрос `/`, правки видны без перезапуска.

Разделы страницы: загрузка фото (одиночная и пакетная), карточка
результата с топ-5 и вкусовой диаграммой, панель статистики, каталог с
поиском и фильтром. Эндпоинты, которые вызывает страница, — `docs/API.md`.
