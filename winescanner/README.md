# winescanner/ — код сервиса

```
winescanner/
  __init__.py
  app.py                      — FastAPI-приложение: загрузка моделей,
                                эндпоинты (docs/API.md), логика пайплайна
                                (ARCHITECTURE.md)
  producer_aliases.json       — алиасы производителей для реранкинга
  grape_aliases.json          — алиасы сортов винограда для реранкинга
  catalog_token_df.pkl        — частоты слов каталога (редкость токена для реранкинга)
  catalog_low_res_photos.csv  — позиции с эталонным фото низкого разрешения
  static/
    index.html                — страница поиска, один файл без сборки
    svoe-vino-logo.svg         — логотип
    grape-decor.svg            — декоративная иллюстрация
```

Модули `prompt_v4.py`, `retrievers/`, `preprocessing/` лежат уровнем выше
(корень репозитория) — их импортирует `app.py`.

## Конфигурация

Все настройки (ключ доступа, флаг контрактного эндпоинта, порог
уверенности, размер топ-N, путь к данным, адрес vLLM) читаются из
переменных окружения — см. `.env.example` и `docs/DEPLOYMENT.md`. Без
`.env` — безопасные значения по умолчанию.

## Не входит в репозиторий

- Веса `yolo11l.pt` для экспериментального BOTTLE_CROP (выключен по
  умолчанию) — скачиваются отдельно при необходимости.
- Рабочие журналы (`predict_log.jsonl`, `marks_log.jsonl`, `query_log/`,
  `batch_staging/`) — создаются при запуске, в git не попадают (`.gitignore`).
